# 共通設定

## 日付と曜日の取得（最重要）

実行環境はJSTです。**曜日は必ずこのコマンドの出力を使うこと。絶対に推測しない。**

```bash
JST_DATE=$(TZ=Asia/Tokyo date +%Y-%m-%d)
JST_WEEKDAY=$(TZ=Asia/Tokyo date +%A)
JST_WEEKDAY_JA=$(TZ=Asia/Tokyo date +%u | awk '{split("月火水木金土日",a,""); print a[$1]"曜日"}')
YESTERDAY=$(TZ=Asia/Tokyo date -v-1d +%Y-%m-%d)
YESTERDAY_WEEKDAY_JA=$(TZ=Asia/Tokyo date -v-1d +%u | awk '{split("月火水木金土日",a,""); print a[$1]"曜日"}')
echo "今日: $JST_DATE ($JST_WEEKDAY_JA) / 昨日: $YESTERDAY ($YESTERDAY_WEEKDAY_JA)"
```

⚠️ **曜日に関する絶対ルール:**
- レポート内で「今日は○曜日」「昨日は○曜日」と書く場合、必ず上記コマンドの出力結果を使うこと
- 日付から曜日を計算・推測してはならない。AIの曜日計算は信頼できない
- 「週の始まり」「週末」等の表現も、上記の曜日出力と矛盾しないこと
